# ibc-contracts Support

Need help with `ibc-contracts`? The following resources are the best places to find answers and reach the community.

## Documentation

Documentation lives in this repository. Useful starting points include:

- [README](./README.md) for the project structure, build requirements, and how to run the unit and end-to-end test suites.
- [Security Assumptions](./README.md#security-assumptions) for the trust assumptions the protocol makes.
- [UPGRADEABILITY.md](./UPGRADEABILITY.md) for the upgrade model of the deployed contracts.
- [RELEASES.md](./RELEASES.md) for how each component is versioned and which release lines are supported.
- [Architecture Decision Records](./docs/adr) for the reasoning behind design decisions.
- [Audit reports](./docs/audits) for third-party reviews of the contracts.
- [Logging](./docs/logging.md), [metrics](./docs/metrics.md), and [tracing](./docs/tracing.md) for operating the off-chain components.

The wider IBC documentation is at [ibc.cosmos.network](https://ibc.cosmos.network).

## Discussions and chat

- [GitHub Discussions](https://github.com/cosmos/ibc-contracts/discussions) for questions, ideas, and early proposals.
- The [Interchain Discord](https://discord.com/invite/interchain) for questions and coordination with the team and community.
- Community calls, open to all and recorded, with a public calendar, for synchronous design and roadmap discussion. Agendas are filed using the [contributor call template](./.github/ISSUE_TEMPLATE/contributor-call.md) so that anyone can add an item, and notes are published afterward.

> [!NOTE]
> Chat is expected to move to a shared community Discord server, per the Cosmos project consistency guidelines. Add the channel links here at that point and retire the old ones on a stated date — leaving two live homes for the same conversation splits the community.

## Issues

`ibc-contracts` issues are tracked in the [GitHub issues tab](https://github.com/cosmos/ibc-contracts/issues). Before opening a new issue, [search the existing issues](https://github.com/cosmos/ibc-contracts/issues) to see if your problem has already been reported.

For guidance on reporting bugs and what to include, see the [contributing guidelines](./CONTRIBUTING.md#reporting-bugs).

> [!NOTE]
> Please don't file an issue to ask a question. Use Discussions or chat instead.

## Security issues

Do not report security vulnerabilities through any of the channels above. Follow the coordinated disclosure process in [SECURITY.md](./SECURITY.md).

## Accounts

A [GitHub account](https://github.com) is required to open issues. Chat is optional, but useful for asking questions and chatting with the community.
