# Adopters

This file records known usages of `ibc-contracts`. It exists so prospective users can see who relies on the project, and so the community can find each other.

> [!IMPORTANT]
> This file needs seeding with real entries. Cosmos requires at least one entry with a publicly verifiable reference in the form of a URL or citable article. Named rows with links are the deliverable here. For on-chain deployments the bar is easy to clear — a block explorer link to the deployed `ICS26Router` or Solana program is a public reference — so an empty ADOPTERS.md would understate a verifiable adoption story rather than reflect a missing one.

## How to add yourself

Open a pull request adding a row below. You need:

- the organization, chain, or project name;
- what you use `ibc-contracts` for, in a sentence;
- whether the usage is in production, in a pilot, or in development;
- **a publicly verifiable reference** — a block explorer link to the deployed contracts or programs, documentation, a blog post, a conference talk, a repository, or a press article. This is required. An entry with no public link cannot be verified and will not be merged.

You do not have to be the adopter to add an entry. If you know of a public usage and can link to evidence of it, add it. See Defining Adopters for what counts.

To be removed, or to change how you are described, open a pull request or raise it with the maintainers. No justification needed.
